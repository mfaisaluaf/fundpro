## Bug Fixes

### 1. Salary Bucket Phantom -10,000 Bank Entry
**Problem:** ATM withdrawal of Rs 10,000 from Salary Bank showed an extra "-10,000 Bank" on the dashboard Salary Bucket card.
**Root Cause:** Income transaction used payment_method "Bank Transfer" which mapped to location "Bank Transfer", while ATM reallocation used location "Bank" — two different keys for the same account.
**Fix:** Normalized all non-Cash/CC/Receivable/Payable payment methods to `'Bank'` in SQL CASE statement in server.js (both `/api/funds/:id/locations` and `/api/funds-with-locations` endpoints).
```sql
CASE
  WHEN payment_method = 'Cash' THEN 'Cash'
  WHEN payment_method LIKE '%Credit Card%' THEN NULL
  WHEN payment_method = 'Receivable' THEN NULL
  WHEN payment_method = 'Payable' THEN NULL
  ELSE 'Bank'
END as location
```

### 2. fundsLocations Stale After Adding Transaction
**Problem:** After adding a transaction on Personal workspace, the Salary Bucket card didn't refresh — required manual page reload.
**Fix:** Updated `fetchData()` in Dashboard.jsx to also call `getFundsWithLocations('personal')` when workspace is personal.

### 3. Loan Given Showing Under Income Type
**Problem:** "Loan Given" sub-category appeared in the Income category dropdown despite being unchecked for income in allowed_types.
**Root Cause:** Only parent categories were filtered by allowed_types. Sub-categories were shown unfiltered.
**Fix:** Added sub-category filtering in AddTransactionModal:
```jsx
const subCategories = (selectedMainCategory?.children || []).filter(sub => {
  if (sub.allowed_types !== null && sub.allowed_types !== undefined) {
    return sub.allowed_types.split(',').filter(Boolean).includes(formData.type)
  }
  return true
})
```

### 4. Workspace Not Persisting on Refresh
**Problem:** Active workspace always reset to "Office" on page refresh.
**Fix:** Save/load activeWorkspace to/from localStorage in MainLayout.jsx.
